# 08. Tuplas, sets y colecciones

## Concepto

Una tupla conserva una secuencia que no puede modificarse. Un set reúne elementos únicos y no garantiza un orden de recorrido. Elegir una colección depende del uso de los datos.

## Referencia disponible
