# 09. Funciones

## Concepto

Una función agrupa instrucciones. Los parámetros reciben datos y return entrega un resultado a quien llama. Mostrar un valor con print no equivale a devolverlo.

## Referencia disponible

Definición, llamadas, parámetros, retorno y valores por defecto.

Ejecuta `python fundamentos/09-funciones/main.py` desde la raíz del repositorio.

`main.py` contiene un ejemplo de referencia. Los archivos adicionales, cuando existen, conservan variantes para comparar enfoques.

## Práctica propuesta

Escribe tiene_contenido(texto) para devolver un booleano. Llámala con texto normal, espacios solos y cadena vacía.

Escribe tu intento en un archivo aparte. Predice la salida antes de ejecutar.

## Comprobación

La función devuelve un resultado; quien la llama decide si mostrarlo o usarlo en una condición.

## Alcance

Los ejemplos adicionales incluyen funciones anidadas, args y kwargs.
