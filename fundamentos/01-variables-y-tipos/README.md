# 01. Variables y tipos

## Concepto

Un nombre se asocia a un valor mediante una asignación. Los valores tienen tipos como int, float, str y bool. Reasignar un nombre cambia el valor al que se refiere.

## Referencia disponible

Asignación y reasignación; salida con print; tipos con type; conversiones básicas.

Ejecuta `python fundamentos/01-variables-y-tipos/main.py` desde la raíz del repositorio.

`main.py` contiene un ejemplo de referencia. Los archivos adicionales, cuando existen, conservan variantes para comparar enfoques.

## Práctica propuesta

Crea una variable tipo con el valor pdf, muéstrala, reasígnala a imagen y vuelve a mostrarla.

Escribe tu intento en un archivo aparte. Predice la salida antes de ejecutar.

## Comprobación

Distingue un string literal de un nombre de variable y predice ambos resultados.

## Alcance

El ejemplo principal incluye conversiones; los otros archivos amplían la práctica de variables y tipos.
