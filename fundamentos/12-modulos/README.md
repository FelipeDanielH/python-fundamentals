# Módulos

Un módulo es un archivo Python que permite organizar y reutilizar funciones. Puedes importar un módulo y acceder a sus funciones mediante su nombre.

## Ejemplo inicial

En `ejemplo-inicial/`, `calculadora.py` define `sumar` y `restar`. `app.py` importa esas funciones mediante el módulo y muestra también ejemplos de `math` y `random`, de la biblioteca estándar.

Desde la raíz del repositorio:

```text
python fundamentos/12-modulos/ejemplo-inicial/app.py
```

El comentario de ejecución del ejemplo conserva la ruta original del archivo; utiliza el comando anterior para su ubicación actual.

Antes de ejecutar, predice los resultados de las operaciones. Luego cambia los argumentos y comprueba qué parte del código se ejecuta al importar el módulo.
