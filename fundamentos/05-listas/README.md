# 05. Listas

## Concepto

Una lista conserva elementos en orden y permite modificarlos. Los índices empiezan en cero; un índice negativo consulta desde el final.

## Referencia disponible

Creación, acceso, modificación, longitud y recorrido de listas.

Ejecuta `python fundamentos/05-listas/main.py` desde la raíz del repositorio.

`main.py` contiene un ejemplo de referencia. Los archivos adicionales, cuando existen, conservan variantes para comparar enfoques.

## Práctica propuesta

Crea una lista de tres nombres de archivos. Agrega uno, elimina otro y muestra cada nombre restante.

Escribe tu intento en un archivo aparte. Predice la salida antes de ejecutar.

## Comprobación

Comprueba el orden final y explica la diferencia entre un elemento y la lista completa.

## Alcance

La comprensión de listas del ejemplo es una ampliación del recorrido básico.
