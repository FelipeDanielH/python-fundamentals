# 06. Diccionarios

## Concepto

Un diccionario relaciona claves con valores. Consultar una clave con corchetes requiere que exista; los valores pueden incluir otras colecciones.

## Referencia disponible

Acceso por clave, actualización, get, items y datos anidados.

Ejecuta `python fundamentos/06-diccionarios/main.py` desde la raíz del repositorio.

`main.py` contiene un ejemplo de referencia. Los archivos adicionales, cuando existen, conservan variantes para comparar enfoques.

## Práctica propuesta

Crea una lista con dos diccionarios que tengan id y texto. Recorre la lista y muestra el identificador y el estado del texto.

Escribe tu intento en un archivo aparte. Predice la salida antes de ejecutar.

## Comprobación

El elemento de cada vuelta es el diccionario completo; explica cómo accedes a su texto.

## Alcance

get e items amplían las formas de consultar y recorrer diccionarios.
