# 04. Condicionales

## Concepto

if ejecuta un bloque cuando su condición se cumple. elif comprueba alternativas y else cubre los casos restantes. La indentación delimita cada bloque.

## Referencia disponible

Condiciones, alternativas y combinación de comparaciones.

Ejecuta `python fundamentos/04-condicionales/main.py` desde la raíz del repositorio.

`main.py` contiene un ejemplo de referencia. Los archivos adicionales, cuando existen, conservan variantes para comparar enfoques.

## Práctica propuesta

Dado un texto, muestra Texto vacío si solo contiene espacios o está vacío; en caso contrario, muestra Texto con contenido.

Escribe tu intento en un archivo aparte. Predice la salida antes de ejecutar.

## Comprobación

Prueba cadena vacía, espacios solos y un texto con contenido.

## Alcance

Hay variantes con edad, temperatura y una escala de notas de ejemplo de 0 a 10.
