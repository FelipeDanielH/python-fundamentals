Este repositorio crece junto con mi aprendizaje. Los ejemplos sirven como referencia para volver a un concepto, experimentar y practicar. El contenido se incorpora y mejora de forma gradual.

## Uso

Los ejemplos actuales utilizan la biblioteca estándar de Python y no requieren instalar paquetes externos. Desde la raíz, ejecuta el archivo que quieras revisar:

```text
python fundamentos/01-variables-y-tipos/main.py
python fundamentos/11-excepciones/main.py
```

Cada script es independiente. Lee su README, predice el resultado, ejecútalo y cambia los datos para comprobar tu comprensión.

En Windows, si `python` no está disponible pero tienes el lanzador instalado, puedes usar `py` en su lugar. Las futuras prácticas con dependencias tendrán instrucciones propias.

## Forma de aprender

1. Leer un concepto y su objetivo.
2. Intentar el ejercicio por cuenta propia en un archivo aparte.
3. Consultar una referencia o buscar una explicación ante un bloqueo.
4. Comprobar un caso normal y un fallo relevante.
5. Explicar el flujo y resolver una variante.
